# FFT64三音定点频谱闭环

**报告者**: Codex
**日期**: 2026-09-04
**优先级**: High
**类型**: Enhancement
**状态**: Resolved

## 需求

以`+127=+1`、`-127=-1`的signed-int8对称定点格式生成64点特色波形，经FFT
微码、RAM/cache和真实VSP RTL执行，自动导出频谱CSV和可视化文件，并用VCS与
Verdi完成复验。绘图不得因缺少Matplotlib而阻塞。

## 完成方案

采用5/13/23号频点的三余弦混合波，幅度分别为`0.40/0.28/0.16`，后两项相位为
`+pi/4/-pi/3`。三个奇数频率使波形满足`x[n+32]=-x[n]`。输入按
`q=clip(floor(127*x+0.5),-127,127)`量化，实际范围`[-94,94]`，不使用`-128`且
无削顶。

- 生成器增加`--waveform mixed`，默认bin-8产物保持字节兼容；
- Verilator C++ TB和VCS SV TB从SRAM镜像动态取得执行指数，并把用户显示尺度与
  BFP执行指数分开；mixed使用`Ein=0`、`Eout=6`、输出尺度`64/127`；
- 64个real结果连续位于`0x1000..0x103f`，64个imag结果连续位于
  `0x1040..0x107f`；TB在系统静默后自动扫描，无需手工控制；
- 新增纯标准库`O(N^2)`直接DFT，不调用生成器radix-2 reference，并从整数码
  反查每行q/127数值、拒绝`-128`；
- Graphviz增加64点输入时域图，以及复分量、单边幅度和相对dB三种频谱图，不需要
  Matplotlib或NumPy；
- VPD已转换为FSDB，Verdi脚本预置FFT控制、cache/RAM和逐bin `real`/Q16.16信号。

## 验证证据

### Verilator

```text
PASS fft64_vsp_memory_system_tb: 1646 checks, 449 actions, 46125 cycles,
45 I-cache misses, 72 D-cache read misses, 1708 shared-RAM beats;
BFP Ein=0 Eout=6, value_scale=64/127
```

### VCS O-2018.09-SP2

```text
PASS fft64_vsp_vcs_tb: 411 checks, 449 actions, 46440 cycles,
45 I-cache misses, 72 D-cache read misses, 1708 RAM beats
```

VCS与Verilator输出HEX的SHA-256均为
`d3ef4a74b54a497b92c2ba72d1be92f4d338276a142e85d9c449f500a4166158`；两套
模拟器的9列频谱CSV SHA-256均为
`53043b3c3f78c9c013527faa7826c83c688f44e60f6274cb41dc376cee3a61e4`。

### 独立DFT

```text
PASS verify_fft64_spectrum:
max_error=0.5101312, rms_error=0.175368301,
top_bins=[5, 59, 13, 51, 23, 41],
parseval_relative_error=0.0169511408
```

fixture测试5项、独立DFT校验器测试5项和static-BFP8 oracle测试8项均通过。
RTL正频率单边幅度为bin 5=`0.393701`、bin 13=`0.278611`、
bin 23=`0.162136`，与设计幅度一致到当前8-bit逐级舍入精度。

## 剩余边界

本issue只收口q/127输入的static-BFP8三音FFT。动态BFP、M8E8 RTL、旧Q8.8/16-bit
FFT、随机与极值向量仍由相应open/in-progress issue跟踪，不能从本结果外推为已经
实现。
