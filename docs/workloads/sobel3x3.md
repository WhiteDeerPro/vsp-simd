# 单通道 3×3 Sobel 驱动 `[工作负载证据]`

## 1. 目的与边界

这是第一个以**宽有符号累加**为中心的代表性负载。它补上 `WSUB_U` 产生负 ACC 值、
再由 `NCLIP_S` 有符号舍入窄化读出的这条路径——此前只有 leaf 测试覆盖，没有负载
证据。它不增加专用 Sobel RTL；C++ 测试程序充当外部 sequencer，向现有
`simd_datapath` 发出微操作。

输入输出均为单通道 unsigned 8-bit 图像，边界零填充，卷积核为：

```text
Gx = -1  0  1     Gy = -1 -2 -1
     -2  0  2           0  0  0
     -1  0  1           1  2  1
```

幅值采用可缩放的 `|Gx| + |Gy|` 近似：

```text
output = min(255, |NCLIP_S(Gx, k)| + |NCLIP_S(Gy, k)|)
```

`k` 是驱动选择的右移量。`k=3` 让 ±1020 的完整梯度范围在窄化后仍可表示（1020/8
= 127.5，正端恰好触发一次饱和）；`k=2` 使有符号 clamp 频繁发生。回归两者都跑。

## 2. 宽域绝对值为什么不可表达，以及它是否重要 `[RTL事实 + 开放问题]`

宽域 `|acc|` **不能**由现有操作组合出来，而且这不是步数问题：所有写 ARF 的操作只有
一个宽输入 `acc_i`，两个数据操作数都是 8-bit VRF 源。没有宽域 NOT、没有宽域位运算、
没有 ARF↔ARF 操作。`WSUB` 算的是 `acc + A - B`，A/B 是 byte 源，因此最多能从累加器
减掉 `255 << align`，无法对 `acc` 取负。「取反 +1」的第一步就没有指令承载。

窄域反而便宜：`SUB` 与 `MAX_S` 都支持 HALF/WORD，元素内借位传播是现成的，所以
`MAX_S(x, SUB(0, x))` 两条就是绝对值，再加一条 `MIN_U(·, 0x7fffffff)` 可复现
`ABS_SAT_S` 在 INT_MIN 处的饱和。真正缺的不是 ABS，而是**ACC→VRF 的导出宽度**：
`NCLIP_*` 和 `NSLICE` 都是每 lane 出一个 byte，把一个 32-bit 累加器值拼成跨 4 lane
的 WORD 元素需要 byte 级转置（多次 `NSLICE` + gather + `SELECT`）。按本负载估算，
只为拿到 16-bit 精度的一个梯度就约需每 4 像素 15 条，与当前整个 kernel 相当。

因此当前映射先窄化再取绝对值，每个分量被 clamp 到 ±127。两个后果不应含糊表述：

- 本映射下 `ADD_SAT_U` 的饱和**不可达**（两分量各 ≤127，和最大 254）。选它是为了
  安全，不是因为测试覆盖了它的饱和；饱和语义由 `simd_exec_tb` 覆盖。
- `k=3` 时 clamp 的代价很小：`|G|` 最大 1020，1020/8 = 127.5，只有这一个极值点被
  clamp 成 127（差 1 LSB），其余全部精确。**8-bit 进 8-bit 出的 Sobel 并不需要宽域
  ABS。** clamp 开始真正影响结果是 `k<3`，或者输出改为 16-bit 图像——那是另一个负载。

所以本负载给出的硬件压力排序是：ACC→VRF 的 HALF 粒度导出优先于宽域 ABS 或有符号
宽 MAX。三者都尚无决定。

## 3. lane 映射与邻列交付

与 Gaussian 相同，每个 lane 对应一个相邻输出像素，同一条微操作处理四个输出。
`SLIDE_UP(1)` 取左邻列，`SLIDE_DOWN(1)` 取右邻列，图像外的 `p[x-1]` 与 `p[x+4]`
由驱动经 `route_lower_i`/`route_upper_i` 交付。宽度非四倍数时 MRF tail mask 禁止
无效 lane 提交 ARF 与 VRF。

关键约束：**route 只作用于 source A**，而 `WSUB` 的两个 VRF 端口都是数据。因此每条
宽减法最多有一个操作数能现场路由，另一个必须先落到独立 VRF row。九个 tap 里需要
六个移位向量（三行各左右），其中四个必须物化：

| 物化 row | 内容 | 被谁使用 |
|---|---|---|
| `v3` | 上一行左移 | Gx 上行、Gy 左列 |
| `v4` | 当前行左移 | Gx 中行 |
| `v5` | 下一行左移 | Gx 下行、Gy 左列 |
| `v6` | 下一行右移 | Gy 右列 |

其余操作数是未移位的行本身（`v0/v1/v2`）或由 source-A route 现场提供。

## 4. 微操作序列

驱动分配（只属于驱动，不是架构约定）：`v0/v1/v2` 三条中心行，`v3..v6` 物化移位行，
`v7/v8` 窄化梯度，`v9/v10` 幅值分量，`v11` 输出；`a0/a1` 两个梯度累加器，`a7` 恒零；
`m0` tail mask。

每个输出块 15 条执行微操作：

| 次序 | 操作 | 说明 |
|---:|---|---|
| 1–4 | `PASS_A` + slide → VRF | 物化 `v3/v4/v5/v6` |
| 5 | `WSUB_U(route(v0), v3)`，align 0，acc `a7`→`a0` | Gx 上行 |
| 6 | `WSUB_U(route(v1), v4)`，align 1，acc `a0`→`a0` | Gx 中行，×2 |
| 7 | `WSUB_U(route(v2), v5)`，align 0，acc `a0`→`a0` | Gx 下行 |
| 8 | `WSUB_U(v3, v5)`，align 0，acc `a7`→`a1` | Gy 左列 |
| 9 | `WSUB_U(v0, v2)`，align 1，acc `a1`→`a1` | Gy 中列，×2 |
| 10 | `WSUB_U(route(v0), v6)`，align 0，acc `a1`→`a1` | Gy 右列 |
| 11–12 | `NCLIP_S(a0/a1, k)` → `v7/v8` | 有符号舍入窄化 + 饱和 |
| 13–14 | `ABS_SAT_S` → `v9/v10` | 窄域取绝对值 |
| 15 | `ADD_SAT_U(v9, v10)` → `v11` | 合成幅值 |

两处值得注意的编纂手法：

- 系数 `1/2/1` 由 `WADD/WSUB` 的**共享 align** 立即数表达，不占 VRF row，也不需要
  乘法器。中心行/中心列的 ×2 就是 `align=1`。
- 首条 `WSUB` 读取恒零的 `a7` 作为 acc 源，省掉每块两次累加器清零；`src_arf_addr`
  与 `dst_arf_addr` 是独立端口，这条手法因此不需要额外操作。

## 5. 计量与对比

| 指标 | Sobel | Gaussian |
|---|---:|---:|
| 每 4 像素微操作 | 15 | 10 |
| 每像素微操作 | 3.75 | 2.5 |
| 其中纯数据搬运 | 4（27%） | 0 |
| 活跃 VRF row | 11 | 5 |
| ARF row | 3（两个累加器 + 恒零） | 1 |
| 乘法类操作 | 0 | 9 |

那 27% 的数据搬运全部来自「route 只有 source A」。若以后测量支持，候选是第二个可
路由操作数，或一条同时交付左右邻列的双 slide；两者都还没有 RTL，也没有面积数据。

Sobel 不需要乘法器：九个 tap 的系数只有 1 和 2，`WADD/WSUB` 的移位对齐就够。这与
Gaussian 的九次 MUL/MAC 形成对照，是 `WADD/WSUB` 三输入形式的直接收益。

## 6. 验证

`sim/sobel3x3_tb.cpp` 用现有状态化数据通路执行全部微操作，并与独立 C++ 零填充
参考模型逐像素比较。覆盖内容：

- 全零、全 255、单点脉冲、确定性 ramp；
- 垂直与水平 step edge，把梯度推到 ±1020 极值；
- 随机宽高与随机像素，250 张；
- `k=3` 与 `k=2` 两种缩放；
- 宽度小于四及非四倍数的 tail mask、图像四边界；
- `SLIDE_UP/DOWN` 的相邻组边界 lane 标记；
- 每条微操作的 `illegal_o` 检查。

测试自带覆盖自证：若整轮没有出现负梯度、没有出现 `NCLIP_S` 饱和，或幅值峰值未
接近 byte 上限，测试直接失败——避免负载退化成只比较零值。当前一轮为 253 张图、
39790 像素、10975 个 SIMD4 块、164625 条微操作，其中 39576 次负梯度和 53835 次饱和
窄化。

运行：

```bash
make test
```
