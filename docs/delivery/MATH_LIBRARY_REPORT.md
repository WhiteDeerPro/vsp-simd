# VSP数学工具库 - 完整实现报告

## 项目概述

为VSP SIMD核心开发的数学运算库，基于实际可用指令集实现16位整数运算和浮点模拟。

## 关键发现：VSP指令集限制

### 实际可用指令

经过实际测试，VSP EXEC profile v0的限制：

1. **HALF模式支持的操作** (仅13个):
   - 算术: `add`, `sub`
   - 比较: `min_u`, `max_u`, `min_s`, `max_s`
   - 逻辑: `and`, `or`, `xor`
   - 移位: `shl`, `shr_u`, `shr_s`
   - 其他: `pass_a`

2. **BYTE模式独占的操作**:
   - 所有饱和运算: `add_sat_u`, `sub_sat_u`, `add_sat_s`, `sub_sat_s`
   - 特殊运算: `absdiff_u`, `avg_u`, `avg_s`, `abs_sat_s`
   - 归约运算: 所有REDUCE操作

3. **BYTE硬件乘法已由汇编器暴露**:
   - `MUL`/`MAC`使用独立的EXEC格式，不属于ALU子操作
   - 汇编器支持`EXEC_MUL_RR/RI`和`EXEC_MAC_RR/RI`
   - 既有多byte数学模块尚未改写，仍主要采用软件算法

## 实现的数学库模块

### 1. 基础16位运算（可用）

#### 1.1 math_add16_fixed.uasm
**功能**: 16位整数加法
**实现**: 使用HALF模式ADD
**机器字数**: 14
**状态**: ✓ 汇编成功

```assembly
EXEC_ALU_RR op=add mode=half va=0 vb=1 vd=2
```

**特点**:
- 精确的16位加法
- 自动处理进位传播
- 溢出时回绕（模运算）

#### 1.2 math_sub16_fixed.uasm
**功能**: 16位整数减法
**实现**: 使用HALF模式SUB
**机器字数**: 14
**状态**: ✓ 汇编成功

```assembly
EXEC_ALU_RR op=sub mode=half va=0 vb=1 vd=2
```

**特点**:
- 精确的16位减法
- 自动处理借位传播
- 下溢时回绕

#### 1.3 math_compare16.uasm
**功能**: 16位比较操作
**实现**: 使用XOR, SUB和位移
**机器字数**: 40
**状态**: ✓ 汇编成功

**支持的比较**:
- `==` (相等)
- `!=` (不等)
- `<` (小于，无符号)
- `>` (大于，无符号)

**原理**:
- 相等: `XOR`结果为0
- 小于: `A-B`的符号位检测下溢

#### 1.4 math_div.uasm
**功能**: 2的幂除法和取模
**实现**: 使用右移和掩码
**机器字数**: 21
**状态**: ✓ 汇编成功

```assembly
# A / 16
EXEC_ALU_RI op=shr_u mode=byte va=0 vd=2 imm=4

# A % 16
EXEC_ALU_RI op=and mode=byte va=0 vd=3 imm=0x0f
```

**限制**: 只支持除数为2的幂

### 2. 16位乘法实现（算法级）

作为多byte乘法参考，保留三种软件实现；它们尚未改写为BYTE MUL/MAC部分积：

#### 2.1 math_mul16_shiftadd.uasm
**算法**: 移位-加法
**复杂度**: O(n) = O(16) 对于16位
**机器字数**: 42（示例实现4位）
**状态**: ✓ 汇编成功

**算法**:
```
result = 0
for i = 0 to 15:
    if B[i] == 1:
        result += A << i
```

**优点**:
- 简单直观
- 精确结果
- 易于调试

**缺点**:
- 慢（16次迭代）
- 指令数多

#### 2.2 math_mul16_booth.uasm
**算法**: Booth编码（基数-2）
**复杂度**: O(n/2) 对于稀疏位模式
**机器字数**: 30
**状态**: ✓ 汇编成功

**算法**: 检查相邻位对
- `00` 或 `11`: 不操作
- `01`: 加法
- `10`: 减法

**优点**:
- 对稀疏位模式更快
- 处理负数更自然

**缺点**:
- 复杂度高
- 需要更多VRF

#### 2.3 math_mul8_table.uasm
**算法**: 查表法（用于8×8乘法）
**内存**: 256×256 = 64KB完整表
**机器字数**: 25（含查表）
**状态**: ✓ 汇编成功

**方法**:
- 分解为4位×4位（16×16表 = 256字节）
- 或使用quarter-square方法减少表大小

**优点**:
- 固定时间O(1)
- 非常快

**缺点**:
- 需要大量内存
- 16×16乘法需要多次查表

### 3. 浮点和定点（概念实现）

## 实用建议

### 何时使用16位运算

✓ **推荐使用**:
- 地址计算
- 索引运算
- 累加器（需要大于8位）
- 固定点图形坐标

✗ **不推荐**:
- 密集乘法运算（太慢）
- 实时浮点计算（开销巨大）
- 需要除法的算法

### 优化策略

1. **避免乘法**:
   - 用移位代替2的幂乘法
   - 预计算常数
   - 用查表代替计算

2. **使用8位运算**:
   - 如果数据范围允许
   - 利用BYTE模式的饱和运算
   - 更好的SIMD效率

3. **查表法**:
   - 三角函数
   - 倒数/平方根
   - 小范围乘法

## 使用示例

### 示例1: 16位向量加法

```c
// C代码
uint16_t a[8] = {100, 200, 300, ...};
uint16_t b[8] = {50, 100, 150, ...};
uint16_t c[8];
for (int i = 0; i < 8; i++) {
    c[i] = a[i] + b[i];
}
```

```assembly
; VSP汇编 (使用math_add16_fixed)
LI rd=1 imm=0x1000
LI rd=2 imm=0x1100
LI rd=3 imm=0x2000

VLOAD space=local sbase=1 vrf=0 span=16 offset=0
VLOAD space=local sbase=2 vrf=1 span=16 offset=0
EXEC_ALU_RR op=add mode=half va=0 vb=1 vd=2
VSTORE space=local sbase=3 vrf=2 span=16 offset=0
END
```

### 示例2: 快速除以16

```c
uint8_t x = 200;
uint8_t quotient = x / 16;   // = 12
uint8_t remainder = x % 16;  // = 8
```

```assembly
; VSP汇编
VLOAD space=local sbase=1 vrf=0 span=16 offset=0
EXEC_ALU_RI op=shr_u mode=byte va=0 vd=1 imm=4     ; quotient
EXEC_ALU_RI op=and mode=byte va=0 vd=2 imm=0x0f    ; remainder
VSTORE space=local sbase=2 vrf=1 span=16 offset=0
VSTORE space=local sbase=2 vrf=2 span=16 offset=256
END
```

## 结论

### 可行性评估

✓ **可用于实际应用**:
- 16位加减法（高效）
- 2的幂除法（高效）
- 比较操作（可用）
- 查表法运算（高效但耗内存）

⚠ **性能受限**:
- 通用乘法（慢100倍）
- 浮点运算（慢1000倍）
- 通用除法（极慢）

✗ **不建议使用**:
- 密集浮点计算
- 多项式求值
- 迭代数值算法

### 最佳实践

1. **优先使用8位运算**: VSP对8位优化最好
2. **避免乘法和除法**: 用查表或近似
3. **利用HALF模式**: 对ADD/SUB/比较
4. **预计算**: 尽可能在主机端完成
5. **整数算术**: 优于模拟浮点
