## 机器码格式

所有`.hex`文件使用标准格式：
- 每行一个32位字
- 十六进制表示（8个字符）
- 小端序
- 可直接用SystemVerilog `$readmemh()` 加载

示例：
```
c4080000    # LI rd=1 imm=0x1000 (header)
00001000    # LI rd=1 imm=0x1000 (immediate body)
b4000420    # VLOAD space=local sbase=1 vrf=0 span=16 (header)
00000000    # VLOAD offset=0 (body)
```

## 限制和注意事项

1. **架构限制**:
   - 无slide/route编码支持
   - 仅支持点级和垂直简化操作
   - 完整2D模板需要架构扩展

2. **内存对齐**:
   - 所有地址必须4字节对齐
   - span参数为0表示4×组数字节

3. **寄存器限制**:
   - 状态寄存器: 32个 (s0-s31)
   - 向量寄存器: 16行 (v0-v15)
   - 累加器寄存器: 8行 (a0-a7)

## 测试建议

1. **确定性输入**: 使用全0、全255、渐变、棋盘等模式
2. **边界条件**: 测试图像边缘、非4倍数宽度
3. **饱和行为**: 验证ADD_SAT_U等指令的饱和点
4. **参考模型**: 与C++实现逐像素比较
