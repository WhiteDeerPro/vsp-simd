# M8E8逐元素补码浮点数值契约

## 定位

M8E8是面向VSP的自定义16位逐元素浮点候选格式。它不是IEEE-754，也不是
`bfloat16`。当前交付仅包含bit-exact软件数值oracle和内存ABI；尚未实现RTL、微码
或RAM/cache执行闭环，因此不能据此宣称硬件已经支持M8E8。

参考实现为[`tools/vsp_m8e8.py`](../../tools/vsp_m8e8.py)，纯数值回归为
[`sim/vsp_m8e8_tb.py`](../../sim/vsp_m8e8_tb.py)。两者只使用整数和Python
`Fraction`，不会用宿主机二进制浮点充当golden。

## 编码与数值

每个数由两个独立的8位二补码整数构成：

```text
M : signed int8 mantissa
E : signed int8 exponent
value = M * 2^(E - 7)
```

没有专用符号位；`M`的二补码符号就是数值符号。`E`没有bias，范围为
`[-128, 127]`。

规范编码规则如下：

- 零只有`(M=0, E=0)`一种编码；
- 非零数必须满足`64 <= abs(M) <= 127`；
- `M=-128`不是规范尾数，必须精确重规范为`M=-64, E=E+1`；
- 不编码NaN、无穷或非规格数。

例如：

```text
( 64,   0) =  0.5
(-64,   1) = -1.0
(127,   0) =  127/128
( 64, -128) = 2^-129
```

该规范化约束消除了相邻指数之间的重复表示。包含规范零在内，格式共有32769个
规范有限编码。

## 舍入、溢出与下溢

普通运算先形成无限精度有理数，再一次性量化到M8E8。尾数舍入采用与现有
`NCLIP_S`一致的round-to-nearest-up：选择最近的可表示尾数；精确中点向正无穷
方向选择。因此正、负中点并不关于零对称：`64.5 -> 65`，而`-64.5 -> -64`。

格式不使用NaN/Inf，边界策略为：

- 最大有限绝对值为`127 * 2^120`；超出正负端点时，对称饱和到
  `(M=+/-127, E=127)`，置`overflow=1`和`inexact=1`；
- 最小规范绝对值为`2^-129`；任何非零且绝对值小于该值的结果都flush为规范零，
  置`underflow=1`和`inexact=1`；
- 精确零不置下溢；正好位于任一有限端点也不置溢出；
- 普通舍入改变数值时只置`inexact=1`。

每次结果同时返回`number`、`overflow`、`underflow`和`inexact`。溢出与下溢不会
同时置位。

## ADD、SUB和MUL语义

软件oracle定义：

```text
ADD(a,b) = quantize(decode(a) + decode(b))
SUB(a,b) = quantize(decode(a) - decode(b))
MUL(a,b) = quantize(decode(a) * decode(b))
```

也就是每个输入先按精确值解释，中间计算无限精度，仅在最终结果处执行一次上述
量化。未来RTL若采用guard/round/sticky位、分级规格化或提前截断，仍必须在所有
输入上产生相同的规范结果和状态位。

## SRAM ABI

逐元素M8E8采用structure-of-arrays（SoA），而不是`M,E,M,E...`交织布局：

```text
mantissa_base + i : M[i]的二补码字节
exponent_base + i : E[i]的二补码字节
```

两个数组长度相同，下标一一对应。SoA允许当前byte lane直接加载一整组16个尾数或
16个指数，避免交织布局引入跨lane拆包。零的指数也必须写成`0x00`；例如
`M=-64,E=1`编码为mantissa字节`0xc0`、exponent字节`0x01`。

## 验证范围与RTL入口条件

现有回归覆盖：已知精确值、规范零、`-128`重规范化、正负tie、编码/解码、SoA
round-trip、上下溢状态、ADD/SUB/MUL、全部32769个规范编码的穷举round-trip，
以及固定种子的随机算术性质。

```bash
make test-vsp-m8e8
```

进入RTL实现前仍需明确并验证：

- 每lane状态如何汇总到指令级sticky flags；
- ADD/SUB的指数差截断上限和guard/round/sticky实现；
- MUL指数加法的有符号溢出检测；
- 规格化、饱和与flush-zero在流水线中的周期和回压行为；
- SRAM异常状态是否另设连续结果区，以及软件如何读取。

只有RTL、汇编/微码、RAM/cache路径、VCS/Verilator differential test均与本oracle
一致后，才能把M8E8标记为硬件完成。
