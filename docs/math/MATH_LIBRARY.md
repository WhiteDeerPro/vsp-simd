# VSP数学工具库完整文档

## 概述

本数学工具库为VSP SIMD核心提供16位整数和浮点运算支持。由于VSP原生支持8位SIMD操作，所有16位运算通过算法分解和组合实现。

## 库内容

### 1. 基础整数运算

#### 1.1 16位加法 (math_add16)
**功能**: 16位无符号/有符号整数加法
**操作**: `C = A + B`
**模式**:
- 标准加法 (HALF模式)
- 饱和加法 (防溢出)

**指令**: 23条
**应用**: 地址计算、累加器、像素值累加

```
输入:  A = 0x1234, B = 0x5678
输出:  C = 0x68AC (标准)
      C = 0xFFFF (饱和, 如果溢出)
```

#### 1.2 16位减法 (math_sub16)
**功能**: 16位无符号/有符号整数减法
**操作**: `C = A - B`
**模式**:
- 标准减法
- 无符号饱和减法 (下溢时钳位到0)
- 有符号饱和减法 (钳位到范围内)

**指令**: 27条
**应用**: 距离计算、差分编码

```
输入:  A = 0x5678, B = 0x1234
输出:  C = 0x4444 (标准)
      C = 0x0000 (饱和, 如果B > A)
```

#### 1.3 16位乘法 (math_mul16_complete)
**功能**: 完整的16位×16位→32位无符号乘法
**算法**: Karatsuba分解
```
(A_hi×256 + A_lo) × (B_hi×256 + B_lo)
= A_hi×B_hi×65536 + (A_hi×B_lo + A_lo×B_hi)×256 + A_lo×B_lo
```

**分解步骤**:
1. 提取高低字节: A_hi, A_lo, B_hi, B_lo
2. 计算4个部分积: P0, P1, P2, P3
3. 对齐并累加: 处理进位传播
4. 组合32位结果

**指令**: 42条 (每次迭代)
**应用**: 面积计算、缩放、定点乘法

```
输入:  A = 0x1234, B = 0x0100
输出:  C = 0x00123400 (32位)
```

#### 1.4 16位比较 (math_compare16)
**功能**: 完整的比较操作集
**操作**: `==, !=, <, >, <=, >=`
**返回**: 每个元素0x0000 (假) 或 0xFFFF (真)

**指令**: 38条
**应用**: 条件处理、排序、筛选

```
输入:  A = 0x1234, B = 0x5678
输出:  A < B  = 0xFFFF (真)
      A == B = 0x0000 (假)
      A > B  = 0x0000 (假)
```

#### 1.5 整数除法 (math_div)
**功能**: 除法和取模运算
**方法**:
- 常数2的幂: 移位实现 (高效)
- 一般除法: 倒数近似 + 乘法 (需迭代)

**指令**: 19条 (2的幂除法)
**应用**: 平均值、归一化

```
输入:  A = 0x1234
操作:  A / 16 = 0x0123 (右移4位)
      A % 16 = 0x0004 (与0x0F)
```

### 2. 定点运算

#### 2.1 Q8.8定点格式
**布局**: `SSSSSSSS.FFFFFFFF` (1符号+7整数+8小数)
**范围**: -128.0 到 +127.99609375
**精度**: 1/256 = 0.00390625

**用途**:
- 图像处理系数
- 几何变换矩阵
- 颜色空间转换

#### 2.2 Q8.8乘法 (math_q88_mul)
**功能**: 定点数乘法，保持Q8.8格式
**算法**:
```
(A × B) >> 8
```
1. 完整16×16→32位乘法
2. 右移8位恢复小数点
3. 可选舍入

**指令**: 45条
**应用**: 系数乘法、插值计算

```
输入:  A = 1.5 (0x0180), B = 2.25 (0x0240)
输出:  C = 3.375 (0x0360)
计算:  0x0180 × 0x0240 = 0x036000 >> 8 = 0x0360
```

### 3. 浮点运算 (BF16格式)

#### 3.1 FP16格式定义
```
位布局: [S|EEEEEEE|MMMMMMMM]
        15 14-8    7-0

S = 符号位 (1 bit)
E = 指数 (7 bits, 偏置127)
M = 尾数 (8 bits, 隐含前导1)
```

**特殊值**:
- 零: E=0, M=0
- 无穷: E=127, M=0
- NaN: E=127, M≠0
- 非规格数: E=0, M≠0

**范围**: 约±3.4e38
**精度**: ~2.4位十进制

#### 3.2 FP16加法 (math_fp16_add)
**算法步骤**:
1. 提取符号、指数、尾数
2. 对齐指数 (将较小指数的尾数右移)
3. 尾数加法 (考虑符号)
4. 规格化结果 (调整指数，移位尾数使最高位为1)
5. 舍入到8位尾数
6. 打包结果

**指令**: 52条
**应用**: 神经网络推理、科学计算

```
输入:  A = 1.5 (0x3FC0), B = 2.5 (0x4020)
输出:  C = 4.0 (0x4080)
```

### 4. 高级运算

#### 4.1 倒数近似 (math_reciprocal)
**功能**: 计算1/x，用于快速除法
**算法**: Newton-Raphson迭代
```
x_{n+1} = x_n × (2 - input × x_n)
```

**迭代次数**: 2-3次达到8位精度
**指令**: 35条
**应用**: 除法、归一化、透视校正

```
输入:  x = 2.0
输出:  1/x = 0.5
方法:  初始猜测 + 2次Newton迭代
```

#### 4.2 平方根 (math_sqrt)
**功能**: 计算√x
**算法**: Newton-Raphson迭代
```
x_{n+1} = (x_n + input/x_n) / 2
```

**初始猜测**: `x/2 + 1`
**指令**: 38条
**应用**: 向量长度、标准差、距离度量

```
输入:  x = 16.0
输出:  √x = 4.0
迭代:  初始=8.5 → 5.25 → 4.05 → 4.00
```

## 使用示例

### C伪代码到VSP映射

```c
// C代码
uint16_t a[8], b[8], c[8];
for (int i = 0; i < 8; i++) {
    c[i] = a[i] + b[i];
}
```

```assembly
; VSP汇编
    LI rd=1 imm=0x1000          ; a数组基址
    LI rd=2 imm=0x1100          ; b数组基址
    LI rd=3 imm=0x2000          ; c数组基址

    VLOAD space=local sbase=1 vrf=0 span=16 offset=0
    VLOAD space=local sbase=2 vrf=1 span=16 offset=0

    EXEC_ALU_RR op=add mode=half va=0 vb=1 vd=2

    VSTORE space=local sbase=3 vrf=2 span=16 offset=0
```

### 定点乘法示例

```c
// Q8.8 定点乘法
fixed_t a = 1.5;  // 0x0180
fixed_t b = 2.0;  // 0x0200
fixed_t c = (a * b) >> 8;  // = 3.0 = 0x0300
```

在VSP中需要完整的16位乘法后右移8位。

### 浮点加法示例

```c
// BF16 浮点加法
float16 a = 1.5;
float16 b = 2.5;
float16 c = a + b;  // = 4.0
```

需要指数对齐、尾数加法、规格化等多步操作。

## 实现限制

### 当前限制
1. **无硬件16位乘法器**: 必须用8位MUL分解
2. **无跨lane进位**: HALF模式可以，BYTE模式需手动处理
3. **无除法指令**: 必须用倒数近似或迭代算法
4. **无浮点单元**: 所有FP操作都是软件模拟

### 精度考虑
- **整数运算**: 精确
- **定点Q8.8**: 精确到1/256
- **浮点BF16**: ~2.4位十进制精度
- **迭代算法**: 取决于迭代次数

### 性能考虑
- **向量化优势**: 同时处理8个16位值
- **指令开销**: 16位操作比8位操作慢2-5倍
- **内存带宽**: 16位数据是8位的2倍
