# VSP数学工具库完整文档

## 概述

本目录汇总VSP SIMD核心的整数、定点和数值算法材料。VSP原生执行路径以8位SIMD
为主；部分16位示例可使用HALF模式，另一些文件仍只是可汇编的算法轮廓。

> **状态修正（2026-09-04）**：VSP当前没有可执行的BF16加法，也没有IEEE-754
> 浮点单元。旧`math_fp16_add.uasm`采用错误标注的`1+7+8`布局，并缺少真实的
> 拆包、指数对齐、进位、规格化、舍入和特殊值处理。汇编成功只证明源码能编码，
> 不证明数值功能。FFT使用的拟浮点契约是共享指数的静态BFP8，详见
> [BFP8块浮点数值契约](BLOCK_FLOATING.md)。

## 库内容

### 1. 基础整数运算

#### 1.1 16位加法 (math_add16)
**功能**: 16位无符号/有符号整数加法
**操作**: `C = A + B`
**模式**:
- 标准加法 (HALF模式)
- 饱和加法 (防溢出)

**指令**: 23条
**应用**: 地址计算、累加器、像素值累加

```
输入:  A = 0x1234, B = 0x5678
输出:  C = 0x68AC (标准)
      C = 0xFFFF (饱和, 如果溢出)
```

#### 1.2 16位减法 (math_sub16)
**功能**: 16位无符号/有符号整数减法
**操作**: `C = A - B`
**模式**:
- 标准减法
- 无符号饱和减法 (下溢时钳位到0)
- 有符号饱和减法 (钳位到范围内)

**指令**: 27条
**应用**: 距离计算、差分编码

```
输入:  A = 0x5678, B = 0x1234
输出:  C = 0x4444 (标准)
      C = 0x0000 (饱和, 如果B > A)
```

#### 1.3 16位乘法目标 (math_mul16_complete)
**目标功能**: 16位×16位→32位无符号乘法
**算法**: Karatsuba分解
```
(A_hi×256 + A_lo) × (B_hi×256 + B_lo)
= A_hi×B_hi×65536 + (A_hi×B_lo + A_lo×B_hi)×256 + A_lo×B_lo
```

**分解步骤**:
1. 提取高低字节: A_hi, A_lo, B_hi, B_lo
2. 计算4个部分积: P0, P1, P2, P3
3. 对齐并累加: 处理进位传播
4. 组合32位结果

**指令**: 42条 (每次迭代)
**应用**: 面积计算、缩放、定点乘法

**当前状态**：该分解仍是历史算法材料，尚未完成byte-lane拆包、部分积进位和
32位结果回包的真实RTL数值闭环；不得把“可汇编”写成“完整/精确”。

```
输入:  A = 0x1234, B = 0x0100
输出:  C = 0x00123400 (32位)
```

#### 1.4 16位比较 (math_compare16)
**功能**: 完整的比较操作集
**操作**: `==, !=, <, >, <=, >=`
**返回**: 每个元素0x0000 (假) 或 0xFFFF (真)

**指令**: 38条
**应用**: 条件处理、排序、筛选

```
输入:  A = 0x1234, B = 0x5678
输出:  A < B  = 0xFFFF (真)
      A == B = 0x0000 (假)
      A > B  = 0x0000 (假)
```

#### 1.5 整数除法 (math_div)
**功能**: 除法和取模运算
**方法**:
- 常数2的幂: 移位实现 (高效)
- 一般除法: 倒数近似 + 乘法 (需迭代)

**指令**: 19条 (2的幂除法)
**应用**: 平均值、归一化

```
输入:  A = 0x1234
操作:  A / 16 = 0x0123 (右移4位)
      A % 16 = 0x0004 (与0x0F)
```

### 2. 定点运算

#### 2.1 Q8.8定点格式
**布局**: `SSSSSSSS.FFFFFFFF` (1符号+7整数+8小数)
**范围**: -128.0 到 +127.99609375
**精度**: 1/256 = 0.00390625

**用途**:
- 图像处理系数
- 几何变换矩阵
- 颜色空间转换

#### 2.2 Q8.8乘法 (math_q88_mul)
**目标功能**: 定点数乘法，保持Q8.8格式
**算法**:
```
(A × B) >> 8
```
1. 完整16×16→32位乘法
2. 右移8位恢复小数点
3. 可选舍入

**指令**: 45条
**应用**: 系数乘法、插值计算

**当前状态**：依赖尚未闭环的signed 16x16乘法、舍入和回包，示例结果是目标
语义而非当前RTL实测结果。

```
输入:  A = 1.5 (0x0180), B = 2.25 (0x0240)
输出:  C = 3.375 (0x0360)
计算:  0x0180 × 0x0240 = 0x036000 >> 8 = 0x0360
```

### 3. 拟浮点与BF16状态

#### 3.1 当前可用：静态BFP8解释

BFP8按`x[i] = m[i] * 2^(E-7)`解释signed byte尾数，整个复数块共享有符号
指数`E`。当前FFT每级固定右移一位，概念上同步增加指数；64点六级FFT满足
`Eout=Ein+6`。当前程序从共享SRAM `0x1360`读取复制的`Ein=-2`，在EXEC中生成
复制的`Eout=4`，并经D-cache/shared fabric写到共享SRAM `0x1370`。这条静态指数
路径已随FFT通过Verilator和VCS；它没有运行时headroom检测，因此仍不是动态块浮点。

#### 3.2 自定义逐元素M8E8：数值契约已完成，执行尚未完成

自定义M8E8使用两个signed int8二补码字段且没有独立符号位，逐元素数值为
`M * 2^(E-7)`。规范零、规格化范围、round-to-nearest-up、上下溢状态以及
mantissa/exponent分离的SoA内存ABI，已由精确有理数oracle和穷举回归固化，详见
[M8E8逐元素补码浮点数值契约](M8E8.md)。

当前完成范围仅是软件数值oracle与ABI：尚无M8E8 RTL运算单元、汇编/微码、状态位
归并或RAM/cache仿真闭环，不得标记为硬件可用。执行实现由
[`M8E8补码浮点执行`](../../issues/in-progress/M8E8补码浮点执行-Codex-2026-09-04.md)
跟踪。

#### 3.3 标准bfloat16：未实现

标准bfloat16布局是`[S|EEEEEEEE|FFFFFFF]`，即1位符号、8位指数和7位小数，
指数bias为127。`1.5=0x3fc0`、`2.5=0x4020`和`4.0=0x4080`是格式示例，
不是当前VSP运算结果。

`math_fp16_add.uasm`保留了早期`[S|EEEEEEE|FFFFFFFF]`算法轮廓。它明确省略
条件指数对齐、符号和特殊值处理，并且其byte-mode `shift=8`不能跨lane提取高
字节，8位尾数加法也不能保存进位。该文件没有数值golden或RTL/VCS回归，不能列为
FP16/BF16实现。动态BFP和BF16所需增量由
[`动态块浮点与BF16执行缺口`](../../issues/open/动态块浮点与BF16执行缺口-Codex-2026-09-04.md)
追踪。

### 4. 高级运算

#### 4.1 倒数近似 (math_reciprocal)
**功能**: 计算1/x，用于快速除法
**算法**: Newton-Raphson迭代
```
x_{n+1} = x_n × (2 - input × x_n)
```

**迭代次数**: 2-3次达到8位精度
**指令**: 35条
**应用**: 除法、归一化、透视校正

```
输入:  x = 2.0
输出:  1/x = 0.5
方法:  初始猜测 + 2次Newton迭代
```

#### 4.2 平方根 (math_sqrt)
**功能**: 计算√x
**算法**: Newton-Raphson迭代
```
x_{n+1} = (x_n + input/x_n) / 2
```

**初始猜测**: `x/2 + 1`
**指令**: 38条
**应用**: 向量长度、标准差、距离度量

```
输入:  x = 16.0
输出:  √x = 4.0
迭代:  初始=8.5 → 5.25 → 4.05 → 4.00
```

## 使用示例

### C伪代码到VSP映射

```c
// C代码
uint16_t a[8], b[8], c[8];
for (int i = 0; i < 8; i++) {
    c[i] = a[i] + b[i];
}
```

```assembly
; VSP汇编
    LI rd=1 imm=0x1000          ; a数组基址
    LI rd=2 imm=0x1100          ; b数组基址
    LI rd=3 imm=0x2000          ; c数组基址

    VLOAD space=local sbase=1 vrf=0 span=16 offset=0
    VLOAD space=local sbase=2 vrf=1 span=16 offset=0

    EXEC_ALU_RR op=add mode=half va=0 vb=1 vd=2

    VSTORE space=local sbase=3 vrf=2 span=16 offset=0
```

### 定点乘法示例

```c
// Q8.8 定点乘法
fixed_t a = 1.5;  // 0x0180
fixed_t b = 2.0;  // 0x0200
fixed_t c = (a * b) >> 8;  // = 3.0 = 0x0300
```

在VSP中需要完整的16位乘法后右移8位。

### BF16加法目标示例（当前不可执行）

```c
// BF16 浮点加法
float16 a = 1.5;
float16 b = 2.5;
float16 c = a + b;  // = 4.0
```

正确实现需要逐元素解包、指数对齐、带guard/round/sticky位的有效数运算、规格化、
舍入、特殊值传播和回包。当前仓库没有完成这些步骤。

## 实现限制

### 当前限制
1. **无硬件16位乘法器**: 必须用8位MUL分解
2. **无跨lane进位**: HALF模式可以，BYTE模式需手动处理
3. **无除法指令**: 必须用倒数近似或迭代算法
4. **无浮点执行闭环**: `math_fp16_add.uasm`只是历史轮廓，不是完整软件模拟
5. **无动态headroom路径**: 当前BFP8采用静态stage shift，虽可在RTL中读写
   `Ein/Eout`，但不会根据数据选择shift或逐stage调整指数

### 精度考虑
- **整数运算**: 精确
- **定点Q8.8格式**: 分辨率为1/256；当前组合乘法实现精度尚未通过RTL验证
- **浮点BF16**: 格式本身约2.4位十进制精度，但VSP尚无实现精度结果
- **迭代算法**: 取决于迭代次数

### 性能考虑
- **向量化优势**: 同时处理8个16位值
- **指令开销**: 16位操作比8位操作慢2-5倍
- **内存带宽**: 16位数据是8位的2倍
