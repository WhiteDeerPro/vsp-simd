# VSP数学库超越函数实现计划

## 目标函数

### 三角函数
- sin(x), cos(x), tan(x)
- asin(x), acos(x), atan(x), atan2(y,x)

### 指数对数
- exp(x), exp2(x), exp10(x)
- log(x), log2(x), log10(x)
- pow(x,y)

### 其他函数
- sqrt(x) - 已有基础版本
- 1/x - 已有基础版本
- 1/sqrt(x) (rsqrt)

## 实现策略

### 方法1: 多项式近似
- 泰勒级数/切比雪夫多项式
- 适合范围较小的输入
- 需要多次乘法/MAC

### 方法2: 查找表 + 插值
- 主查找表 (粗粒度)
- 线性/二次插值 (细化)
- 内存换速度

### 方法3: CORDIC算法
- 适合三角/双曲函数
- 只需加法和移位
- 迭代收敛

### 方法4: 范围缩减 + 表
- 利用函数对称性
- 小表覆盖大范围
- 组合多种技巧

## 数据空间布局

```
内存布局:
0x4000-0x4FFF: 三角函数查找表区 (4KB)
  0x4000: sin表 (256项 x 8bit)
  0x4100: cos表 (256项 x 8bit)
  0x4200: tan表 (128项, 范围限制)
  
0x5000-0x5FFF: 指数对数表区 (4KB)
  0x5000: exp表 (256项)
  0x5100: log表 (256项)
  0x5200: 1/x表 (256项)
  0x5300: sqrt表 (256项)

0x6000-0x6FFF: 多项式系数区 (4KB)
  0x6000: 三角函数多项式系数
  0x6100: 指数函数系数
  0x6200: 对数函数系数
```

## Q8.8定点表示

- sin/cos: [-1, 1] → [-256, 256] 映射到 Q8.8
- exp: [0, 8] → [1, 2980] 需要特殊处理
- log: (0, 256] → 对数值
- 角度: [0, 2π] → [0, 255] (256步)
